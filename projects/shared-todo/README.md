# Shared To-Do

A multi-user to-do list with no trusted server, on the ToIP specs through the Apache-2.0 OpenVTC libraries. It demonstrates the basics: self-certifying identifiers, encrypted and signed TSP messages, a list run as a small community with membership credentials and roles, each device checking every change for itself, a relay that holds only ciphertext, private items, and revocation.

Design: `docs/design.md`. Plan: `docs/plan.md`.
